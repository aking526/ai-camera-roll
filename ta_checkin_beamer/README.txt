CIS 5810 TA check-in -- editable Beamer source

The deck has eight slides. The course-expectation slide and three-cycle roadmap
from the previous deck have been removed. The scoring slide now explains SCRFD,
ArcFace, the numerical comparison and the reasons for choosing these tools.
The final slide proposes one experiment; subsequent changes depend on its results.

BUILD
Keep ta_checkin.tex and the assets directory together.
With Tectonic: tectonic ta_checkin.tex
With a full TeX installation: latexmk -pdf ta_checkin.tex
You can also upload this source bundle to Overleaf and compile ta_checkin.tex.

EDIT
All slide text, tables and chart data are in ta_checkin.tex.
The photographs and face crops in assets/ are existing synthetic project images.
Speaker notes appear in each frame's note command and are hidden in the normal
presentation. Change hide notes to show notes to compile a copy with notes pages.

SOURCES
Sources are linked on slides and described in their speaker notes. Saved project
evidence corresponds to repository commit b8c9014066ee32bb119df63ef75748cd3885bf5c.
No new photographs were generated to make this presentation.
