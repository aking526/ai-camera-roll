Each scorer compares a canonical reference image with a crop taken from a generated photo. Every row below shows the exact pair that produced the number, plus the detector's view of the scene. Click any image to see it larger.

Similarity is cosine similarity from −1 to 1. It is not a probability or a percentage, and no threshold has been calibrated, so these numbers do not decide whether an identity or an object is correct.
